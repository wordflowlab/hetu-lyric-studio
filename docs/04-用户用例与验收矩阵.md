# 用户用例与验收矩阵

| 用例 | 正向验收 | 反向验收 |
| --- | --- | --- |
| LY-01 故事人物歌 | 回读固定来源，保存主歌副歌并核对引文 | 错作品、摘要、字节范围不落盘 |
| LY-02 自由曲式 | 可重复副歌，空器乐段有明确种类 | 重复行序、悬空编排拒绝 |
| LY-03 长度检查 | 中文字、数字和字母Unicode计数，英文词数单列 | 不把标点空白或emoji当演唱音节 |
| LY-04 韵脚核对 | 同组显式韵尾相同，缺注音显示未知 | 不自动猜多音字，不以同标签证明听觉押韵 |
| LY-05 逐句备选 | 固定旧句比较及使用，新版清空失效发音 | 旧摘要、错句、删有引用记录拒绝 |
| LY-06 标记歌词导入 | 固定原文预览后导入，保留未知标签 | 缺闭括号、未归段、预算或重复ID拒绝 |
| LY-07 实际试唱 | 固定PCM音频、完整摘要、真实时长和波形 | 损坏头、截断、错采样率、错误摘要拒绝 |
| LY-08 LRC接入 | 多标签、offset、重复副歌按出场对齐 | 逐词扩展、冲突时间、错字和缺行拒绝 |
| LY-09 听审意见 | 固定行与录音对齐摘要，返工后过期 | 不自动解决意见或宣称实际听过 |
| LY-10 接续专业包 | 固定歌词与音频交有声剧／视频并回读 | 不混其他作品授权，不伪造下游成功 |
| LY-11 完整交付 | 歌词TXT、完整HTML、LRC与JSON分块核验 | 部分／过期对齐不导出为当前完整LRC |
| LY-12 热插拔 | 同MCP发现Skill，安装停用卸载重装和旧修订回读 | 不改变其他插件选择、撤权不得访问 |
| LY-13 恢复与并发 | CAS保留输入、同键同参唯一、丢回执原键恢复 | unknown不换键重写，异参拒绝 |
| LY-14 审核界面 | 五页实际浅暗1360/760、键盘、音频、导出取消、重开 | 页可渲染不代替业务或实际音频播放 |

本机与固定正式制品CI分别验证；当前Codex会话实际读取方法、操作两版并回读。Windows/Linux专业实机、真实演唱质量和作者认可不从共享代码推导。可解码、实际听取范围和创作决定分别取证；合成测试音仅验证波形、时间和链路，不能冒充试唱质量。
