# 产品需求

## 背景与第一性原理

故事里的一句话可以成为人物歌或片尾曲。作者需要保留谁在唱、为何唱、主歌怎样推进、副歌怎样重复，以及新歌词在哪次实际试唱中出现问题。Agent善于理解和写作；每轮重新整理段落、行序、变体和时间会反复消耗上下文。软件固定这些工程事实及确定性检查，作者专注阅读、听取与取舍。

## 产品定义与首版完整范围

歌词工坊是按需安装的专业工程，不是生成器或音乐播放器。外部Codex经河图CLI/MCP读取固定作品与同包Skill，准备完整歌词；作者在结构、逐句检查、试听对照、意见和交付五页审阅。

首版涵盖段落与逐句正文、明确演唱编排、Unicode字数约束、显式发音和韵尾组、逐句备选与版本比较、固定PCM16实际音频及波形、LRC预览与固定映射、逐句定位、旧稿意见复核、标记歌词／LRC／HTML交付，以及有声剧和视频接续。手动编辑可用但不成为默认旅程前置。

不推断中文多音字，不把字数当音节，不自动认可唱腔或词曲适配。正典与正式正文归宿主；作曲、合成、演唱和语音识别由外部工具完成。内容外发、费用、声音权利、资产选用与定稿独立决定。

## 价值与边界

按需安装减少普通作者的操作负担。可视化和机器入口读取同一工程；固定数据格式比一次性页面更适合反复修改。本包不新增Core作品类型、数据库、内置Agent、团队权限或支付服务。每次生成可形成有来源、可比较、可接续的成果。
