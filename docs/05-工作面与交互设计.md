# 工作面与交互设计

五页：歌词结构、逐句检查、试听对照、意见与备选、专业交付。打开插件占满工作面，紧凑顶部保留返回、刷新和让AI处理。专业结果先于高级编辑，作者无需填Agent已准备的数据。

结构页按实际编排阅读主歌与重复副歌，句间留白与段落导航；检查页并列歌词、字数、显式音节和韵尾，未知明确；试听页真实audio与波形、逐句时间表联动，可定位当前句，显示旧歌词录音；意见页对照原句与备选，固定来源和过期状态；交付页核对缺口并导出固定文件、准备有声剧和视频接续。

使用宿主共享Radix与覆盖完整文档的静止连续渐变，滚动和长页底部保持连续，纸面和输入稳定实色，浅暗及减少透明度同步。12/14/18/20px最多四档，边框0.5px；交互不靠颜色单独传达。没有固定成果时引导Agent，错误、未知与冲突就地可恢复；不展示技术JSON代替专业阅读。

```mermaid
flowchart LR
 A[作者提出歌曲目标] --> B[Agent读取来源与旧工程]
 B --> C[准备歌词与备选]
 C --> D[作者阅读结构和约束]
 D --> E[接入实际录音并听审]
 E --> F[固定意见与逐句返工]
 F --> D
 F --> G[导出或专业交接]
```
