# Skill与机器接续

包内hetu-lyric-studio通过河图plugins.inspect、capabilities和skills.read发现；它不是Codex插件，不注册新的MCP工具名，也不全局安装同名Skill。宿主热启用后外部Agent再次发现即可读取实际版本。

方法区分从故事写歌词、已有歌词整理、约束与备选比较、实际录音对齐、按固定意见返工、交付与专业接续。执行前读实际Schema与已有成果。歌词与原文关联是创作依据，不要求改编句与原文完全相同；引文自身必须匹配固定字节。

中文多音字、押韵与节奏判断由Agent明确说明依据，缺发音保持未知。录音取自真实工具或作者文件，声音权利、外发、费用与正式选用按本次决定执行；不把保存Take当成已听。未知沿get_operation回读，长任务固定阶段成果和下一步目标。

完整方法归skills/hetu-lyric-studio，操作导航构建生成；宿主能力地图只导航公共入口，专业清单由本包维护。
