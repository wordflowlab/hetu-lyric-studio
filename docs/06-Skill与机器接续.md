# Skill与机器接续

包内hetu-lyric-studio通过河图plugins.inspect、capabilities和skills.read发现；它不是Codex插件，不注册新的MCP工具名，也不全局安装同名Skill。宿主热启用后外部Agent再次发现即可读取实际版本。

方法区分从故事写歌词、已有歌词整理、约束与备选比较、实际录音对齐、按固定意见返工、交付与专业接续。执行前读实际Schema与已有成果。歌词与原文关联是创作依据，不要求改编句与原文完全相同；引文自身必须匹配固定字节。

中文多音字、押韵与节奏判断由Agent明确说明依据，缺发音保持未知。录音取自真实工具或作者文件，声音权利、外发、费用与正式选用按本次决定执行；不把保存Take当成已听。未知沿get_operation回读，长任务固定阶段成果和下一步目标。

完整方法归skills/hetu-lyric-studio，操作导航构建生成；宿主能力地图只导航公共入口，专业清单由本包维护。

## 一次调用的接续规则

| 阶段 | Agent保留的信息 | 退出条件 |
| --- | --- | --- |
| 发现 | 当前安装包SHA、能力SHA、当前作品和确切management_ref | 读取当前包方法与目标动作Schema |
| 读取 | 固定作品／来源、已有专业修订与公开反馈 | 区分已读事实、未知和拟创作内容 |
| 准备 | 完整专业输入、expected_revision、expected_sha256、operation_key | 输入符合专业Schema且来源可核验 |
| 执行 | 同一作品与活动包绑定 | 成功、明确拒绝或结果未知分别处理 |
| 回读 | 固定object_id、revision、sha256和原操作 | 确认内容而非只确认HTTP或进程退出 |
| 接续 | 固定交接记录及下一轮问题 | 由作者阅读、试听、提意见或选择 |

安装、启用、升级、停用后重新发现当前能力；旧包绑定不能继续调用。重新连接客户端不授予整库权限；发现工具或Skill不等于有权读取任何作品。下游专业插件需要独立发现实际安装与Schema，交接引用保持精确WorkRef。

三条常用旅程：故事→歌词结构→明确约束与备选；原歌词／实际录音→真实LRC→逐句听审；固定意见→新专业修订→复核旧录音与对齐→重新交付。缺少实际音频时继续文字创作，不创建虚构Take或时间。界面可用于审核与手动修订，机器主旅程无需打开桌面。
