# 歌词工坊

先发现活动包、精确作品与实际Schema，读取已有工程和固定来源，再经河图稳定CLI/MCP调用本包。不要另装同名Codex插件或新建MCP服务。

从[专业流程](references/workflows.md)选择写词、整理、试唱对齐或返工；[操作地图](references/operations.md)导航实际参数。重复副歌通过独立出场引用同一段落；需要不同歌词就建另一段，不能用相同ID覆盖历史。

字数不是音节，韵尾只比较明确发音标注；缺依据保持未知。试唱必须关联真实固定音频，时间从录音或真实对齐取得，不从字数推断。合成测试音只能验证链路，不冒充演唱。歌词变化后复核旧录音、标记和意见，不能自动宣称解决。

保存携带CAS和原键，未知先get_operation；成功后回读固定修订。专业备选使用不等于正文采纳。外发、付费、声音权利、正式资产选用及定稿沿本次作者决定执行。
